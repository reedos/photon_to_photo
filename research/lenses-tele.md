## Self-check method

`.local/lens-tele/paraxial.py` is a standalone paraxial (y‑νu) sequential ray tracer, written from the standard textbook refraction/propagation recursion (see the file's docstring), that:

1. Loads a `LensDesign` JSON file and applies `scale`.
2. Traces a marginal ray from an object at infinity (`y0=1, u0=0`) through every surface (refracting at each `r`/`n` interface, propagating through each `t`), and computes EFL = `-y0/u_final` and BF = `-y_last/u_final` from the ray's height/angle at the *last* surface — independent of whatever `t` is stored on that last surface, since that's the value being checked.
3. Compares computed EFL/BF against `stated.f`/`stated.bf`.
4. Estimates semi-diameters: sets the entrance-beam (marginal-ray) semi-diameter at surface 1 to `EFL_computed / (2 * Fno_stated)` — this is not an assumption, it is the definition of the full-aperture entrance pupil for a collimated object-at-infinity ray, since that ray has not yet refracted when it reaches surface 1 — then traces it forward to get a real semi-diameter at every surface. A second, field-angle ray is traced from `y0=0` at the patent's half field angle and linearly combined with the marginal ray so it passes through the stop's center (paraxial chief ray). `sd_i = |marginal_i| + |chief_i|` at every surface (a deliberately generous/conservative estimate, not a tight fit).

**Honesty note on the "Fno from stop semi-diameter" check the task asks for:** none of the four patents used here print an effective/clear diameter for *any* surface, including the stop. Because of that, there is no data point independent of the stated Fno to check it against — the traced entrance-pupil semi-diameter is set *from* the stated Fno in step 4 above, so "EFL/(2×entrance-pupil sd) = stated Fno" is true by construction, not a discovery. What the trace *does* discover, non-circularly, is the ray's height *at the stop surface itself* (smaller than the entrance-pupil size, because the front group converges the beam before the stop — normal telephoto behavior) and at every other surface; those are the numbers recorded as each surface's `sd` (`sdSource: "estimated-from-marginal-ray"`). The genuinely independent, non-circular checks in this project are EFL and BF, both of which depend only on `r`/`t`/`n` and pass for all four lenses.

## The D(last)=0.000 finding (p300 / p400 / p500)

US 6,115,188 (the shared Canon patent for the 300/400/500 mm lenses) prints 16 numerical examples. Every one ends its surface table with the last row's thickness printed as `D(n) = 0.00`, and the patent's text nowhere gives a separate `Bf = ...` label (checked with a full-text grep for "Bf", "back focal", "total length" across the patent — the only hits are unrelated prose about design *conditions*, never a numeric value for a specific example). The first attempt at p300.json took that literal `D29 = 0.000` as the patent's stated Bf. The self-check then showed EFL matching to +0.007% (essentially exact) while BF was off by 59.3 mm (computed 59.3221 vs assumed-stated 0.0000). Since EFL and BF are computed from the exact same `r`/`t`/`n` data, a correct EFL with a wildly wrong BF meant the *reading of the patent*, not the transcription, was the error: `D(last)=0.000` is a table-terminator formatting convention in this patent (true across all three examples used here), not a physical claim of zero back focus. Fix: the terminal surface's `t` in each of p300/p400/p500 is recorded as the value our own trace computes (`derived`, not patent-stated), and `stated.bf` is left out of the JSON for those three lenses. p200 (the Nikon patent) does print a separate, real `Bf=67.9864` label and needed no such correction.

## Per-lens notes

### p200 — 200 mm f/2 (Nikon, US 5,490,014)
- "High-aperture-ratio inner-focus telephoto lens", Nikon Corp, inventor Fumio Suzuki. Priority 12/28/1992, filed 12/16/1993, published 2/6/1996. Embodiment 1 of 5 (the patent's other embodiments are all close variants around f=195–198, Fno=2.0).
- Table 1 gives `f = 195.00 mm`, `F.sub.no = 2` (i.e. exactly f/2.0), and separately `Bf 67.9864 67.9864` (same at both infinity and near focus — expected for an inner/floating-focus design). Two variable air gaps are printed (`d11` and `d16`), with object distance `D0 = 1765.5380` mm (raw, patent's own reference — not stated to be "from the sensor"; recorded as-is) at magnification `β = -0.1201`. `focus.method` is recorded as `"floating"` (two groups move) rather than plain `"inner"`, since the table shows two independent variable gaps, not one.
- The raw table's row "22 ∞ (Bf)" is transcribed as its own flat terminal surface (r=null) whose `t` equals the separately-printed Bf, per the schema's convention; row 21 (r=-165.858, d=11.00, air) is a genuine air gap before it, since the patent prints both numbers distinctly.
- **Aperture stop location is uncertain.** The raw numerical table has no "stop" label on any row (unlike the Canon patent below, which prints "R14 = Stop" explicitly). A second AI-assisted read of the patent's descriptive prose reported the stop as sitting "at surface 11, between the second and third lens groups" — transcribed here as `stop: true` on surface index 10 (0-based), flagged clearly in the JSON's own notes as unverified against the primary-source PDF page images (only the OCR'd/HTML text was read, via Google Patents and an AI summarization pass — not the original drawing figures). If precision here matters later (e.g. for a claims-checker on entrance-pupil position), this should be re-verified directly against the patent PDF's Fig. 1.
- Elements/groups counted from the cementing pattern: 12 elements in 9 groups. For context only (not a sourced claim): the current production Nikon AF-S NIKKOR 200mm f/2G ED VR II is publicly specified as 13 elements in 9 groups — groups match exactly, elements are off by one, suggestive of a design lineage but not a citable identification, so `representativeOf` is deliberately left unset.
- Blades (9, rounded) and min-focus (1.9 m) are typical values from that same current Nikon product's spec page (https://www.dpreview.com/products/nikon/lenses/nikon_200_2g_ed_vrii_afs/specifications), explicitly marked `"assumed"` in the JSON since no public source ties this 1992-priority patent to that specific 2015-era product.
- Half field angle / image height are not printed by the patent; assumed Y=21.6 mm (standard 24×36 half-diagonal) for the chief-ray sd estimate, since the patent only says the design covers "an angle of view equivalent to that of a lens with focal length of about 200 mm" for 35 mm format.

### p300 / p400 / p500 — 300/400/500 mm (Canon, US 6,115,188, one shared patent)
- "Optical system and optical apparatus having the same", Canon Inc / Canon Kabushiki Kaisha, inventors Akihiro Nishio, Hideki Ogawa, Makoto Misaka. Priority 10/16/1997 (JP 29957397, plus two more 1997/1998 JP priorities), filed 10/14/1998, published/granted 9/5/2000. An image-stabilization (IS) optical-system patent with 16 numerical examples spanning roughly four focal-length classes (~294/392/490/589 mm). Three of those examples (1, 7, 10) are used here for the 300/400/500 mm lens slots respectively, so those three JSON files share one design lineage and one inner-focus + rear-floating-IS-group architecture. This is deliberate and documented in each file's own `notes`, not an accident of the search.
- **Why this patent, not three separate ones:** the four focal-length classes present in this single patent (~294/392/490/589 mm, all at Fno 2.9/2.9/4.1/4.1) line up almost exactly with Canon's real EF 300mm f/2.8L IS USM, EF 400mm f/2.8L IS USM, EF 500mm f/4L IS USM and EF 600mm f/4L IS USM — the first-generation IS super-telephoto lineup Canon launched in July–September 1999, about a year after this patent's October 1998 filing. That timing/spec match is a strong circumstantial signal but was **not found stated by any public source** (searched photonstophotos, canonwatch, dpreview forums, nikonrumors-equivalent Canon sites) tying US 6,115,188 specifically to those products, so `representativeOf` is left unset on all three files per the task's rule.
- All three examples print the aperture stop explicitly as `R14 = Stop` in the raw table — unlike the Nikon 200 mm lens, this position needed no inference.
- None of the three give a close-focus variable-gap table (only the infinity-focus D-values are printed for these numerical examples), so no `VariableGap` entries are recorded for any of them — recording a plausible-looking close-focus number would have meant inventing it.
- Internal cementing pattern differs slightly example-to-example (e.g. the L3d position is a cemented doublet in Example 1 but a genuine air-spaced pair of singlets in Examples 7 and 10) — each is transcribed exactly as printed rather than forced into a common template. Example 7 (400 mm) additionally has an explicit "fixed stop HP" flat baffle surface between the last lens and the filter block (the patent's own paragraph (a-14) names this), which Examples 1 and 10 don't print.
- Elements/groups counted from each example's own cementing pattern: 300 mm → 15/12, 400 mm → 16/13, 500 mm → 15/12.
- Blade counts and min-focus distances are typical values pulled from Wikipedia's spec tables for the actual, era-matching Canon products (EF 300mm f/2.8L IS USM, EF 400mm f/2.8L IS USM, EF 500mm f/4L IS USM — all first-generation, 1999), explicitly marked `"assumed"` since the tie to this specific patent is circumstantial, not sourced:
  - https://en.wikipedia.org/wiki/Canon_EF_300mm_lens — 9 blades, 2.5 m MFD
  - https://en.wikipedia.org/wiki/Canon_EF_400mm_lens — 9 blades, 3.0 m MFD
  - https://en.wikipedia.org/wiki/Canon_EF_500mm_lens — 8 blades, 4.5 m MFD

## Open problems / uncertainties

1. **p200's aperture-stop surface is not confirmed against the primary source.** It rests on an AI-summarized read of the patent's prose (not the table), not a second independent verification against the original PDF page images. Low risk to the physics (EFL/BF pass regardless, since stop position doesn't affect either), but would affect any entrance-pupil/vignetting visualization built on `stop: true`'s exact position.
2. **No lens in this set has a public source tying it to a named commercial product**, so `representativeOf` is unset on all four — this is compliant with the task's rule ("only fill it when a public source ties the patent example to a product") but means the site can only present these as "patent examples, schematic of the class" for 200/300/400/500 mm, not as named-lens recreations, unless another agent or a later pass finds a citing source.
3. **Every semi-diameter in all four files is `estimated-from-marginal-ray`**, not patent-given — none of the four patents print effective/clear diameters. The estimation method (marginal ray sized from stated Fno, plus chief ray at stated/assumed half field, summed) is documented above and in each file, but it is a paraxial approximation (no pupil aberration, no vignetting factor beyond the crude marginal+chief sum) and will likely oversize some clear apertures relative to the real mechanical barrel — reasonable for a schematic cutaway, not for a precision vignetting model.
4. Did not attempt Japanese-language-only patents (per the brief's "JP with an English text" requirement) beyond what Google Patents' machine translation already surfaced in search snippets — a manual JP-source search was not undertaken given the strength of the English-language finds above.
5. p400's rear-group structure (the extra "fixed stop HP" surface not present in the other two examples) means its element count (16) doesn't simply interpolate between p300 (15) and p500 (15) the way the focal lengths do — this is real (each patent example is independently optimized, not a linear scale of the others), not a transcription inconsistency, but worth flagging so the physics/rendering team doesn't assume a smooth family relationship across the three Canon-sourced lenses.
