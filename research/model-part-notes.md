# Models page: card sentences for the controls that had none

Score loop r6 (10/14/2026). These parts were picked on the Models page and showed a title and no sentence. Each sentence below
is in `NOTES` in `src/app/models.ts`; a part with no sentence at all shows a placeholder built from where it is listed.
No dimension or value is stated: the sentences describe what the control does, as the makers' manuals do.

| Part (body) | Sentence rests on | Source |
|---|---|---|
| Release-mode dial (D850) | Seven modes on the dial (S, CL, CH, Q, Qc, self-timer, mirror up); press the lock release, then turn the dial to the mark | Nikon D850 online manual, "Choosing a Release Mode": https://onlinemanual.nikonimglib.com/d850/en/09_release_mode_01.html (control index: https://onlinemanual.nikonimglib.com/d850/en/02_introduction_01.html, "Release mode dial lock release") |
| AF-ON button (both) | "has the same effect as pressing the shutter-release button halfway" | D850: https://onlinemanual.nikonimglib.com/d850/en/08_focus_01.html ; Z8, Custom Setting a6: https://onlinemanual.nikonimglib.com/z8/en/csma_af_activation_209.html and https://onlinemanual.nikonimglib.com/z8/en/focus_31.html |
| Aperture-coupling lever (D850) | The body's lever moves the lens's aperture lever: pushed to its limit it fully opens the aperture; released, a spring stops the lens down to the set value | Nikon, "Nikon FG / FG20" history page (the automatic stop-down coupling lever): https://imaging.nikon.com/history/chronicle/cousins12-e/index.htm . The D850 manual's control index calls the body part the "meter coupling lever" and does not describe it, so the model's own label ("aperture-coupling lever") is kept and the sentence follows the Nikon history page. |
| Pv and Fn1 buttons (D850) | "During viewfinder photography, you can preview depth of field while the control is pressed" when the button is assigned Preview; button roles are chosen in the menus | D850 Custom Setting f1 / control assignment: https://onlinemanual.nikonimglib.com/d850/en/18_menu_guide_05_f01.html |
| Fn1 and Fn2 buttons (Z8) | Hold the button and turn the command dials; by default Fn1 chooses the shooting menu bank and Fn2 the image area | Nikon Z8 online manual, "The Fn1 and Fn2 Buttons": https://onlinemanual.nikonimglib.com/z8/en/function_button_14.html |
| Live-view button and selector (D850) | Turn the live view selector to photo (or movie), press the button: the mirror is raised and the view through the lens is shown on the monitor; press again to exit | D850 manual, "Live View Photography": https://onlinemanual.nikonimglib.com/d850/en/05_live_view_01.html |
| Multi-selector (both) | Chooses the focus point while the meters are on; used in menus ("press the center of the multi selector" to select); its center button's role is a custom setting (f2) | D850: https://onlinemanual.nikonimglib.com/d850/en/08_focus_01.html and Custom Setting f2 (https://onlinemanual.nikonimglib.com/d850/en/18_menu_guide_05_f04.html lists "f2 Multi selector center button"); Z8: https://onlinemanual.nikonimglib.com/z8/en/focus_31.html and camera body page https://onlinemanual.nikonimglib.com/z8/en/camera_body_9.html ("Multi selector, Using the Menus") |
| Power switch (both) | "Rotating the power switch to D activates the backlights for the buttons and control panels" | D850 control index (https://onlinemanual.nikonimglib.com/d850/en/02_introduction_01.html) and Z8 camera body page (https://onlinemanual.nikonimglib.com/z8/en/camera_body_9.html) |
| Sub-selector (both) | Can be used for focus-point selection in place of the multi selector; pressing its center locks exposure and focus | D850: https://onlinemanual.nikonimglib.com/d850/en/08_focus_01.html ; Z8: https://onlinemanual.nikonimglib.com/z8/en/focus_31.html |
| Four setting buttons (Z8) | BKT, WB, MODE and release-mode buttons on the top plate; release mode is chosen by holding its button and turning the main command dial | Z8 camera body page (https://onlinemanual.nikonimglib.com/z8/en/camera_body_9.html) and "Release Mode": https://onlinemanual.nikonimglib.com/z8/en/release_mode_33.html . Only the release mode's hold-and-turn is stated; the sentence does not claim it for the other three. |
