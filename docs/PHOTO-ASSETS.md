# Published photo assets

Updated October 4, 2026 from ten user-supplied JPEGs. The former six gallery files and their thumbnails were removed. Repeated subjects now use the newly supplied originals.

The gallery uses a 3,200-pixel-long-edge JPEG preview (quality 85), with 320-pixel thumbnails. Selecting a detail loads a quality-88 JPEG retaining the source pixel dimensions. Full-size downloads are deferred until a detail is selected. Play the shot uses the preview plus a separately encoded, source-resolution subject crop (at most 1,800 pixels across) so it does not allocate a 45-megapixel canvas for an animation.

Embedded Display P3 and ProPhoto RGB profiles were converted to sRGB using LittleCMS; existing sRGB files stay in that color space. Published files embed an sRGB profile. EXIF and location metadata are not copied to exports. Camera, lens, aperture, exposure, ISO and available focus distances were read with ExifTool; only the relevant capture facts appear in the catalog. Focus distances are approximate, and absence is displayed as unrecorded. Source originals are untouched.

The Canon 160 mm capture has no matching optical model. Its recorded values remain visible, applying settings is disabled, and its ray chapter explicitly identifies the 50 mm reference illustration. Unknown focus distances use a labeled 10 m assumption only for the illustration; applying other recorded settings does not overwrite the workspace focus with infinity.
